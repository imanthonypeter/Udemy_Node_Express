# Curso de Node.js, Express, MongoDB e PostgreSQL - Matheus Battisti (Udemy)

Este repositório é o meu guia de estudo e acompanhamento das aulas do curso de **Node.js, Express, MongoDB e PostgreSQL** da Udemy, ministrado pelo professor **Matheus Battisti** (Hora de Codar).

## 📚 Sobre o Repositório

Aqui você encontrará os códigos, exercícios e projetos desenvolvidos ao longo das aulas. Cada diretório corresponde a um módulo ou a um conceito específico ensinado no curso. Este espaço serve como material de consulta e revisão de tudo que venho aprendendo sobre o ecossistema Node.js.

## 📂 Estrutura do Projeto (Progresso Atual)

Abaixo estão os módulos e tópicos que já foram estudados e documentados neste repositório até o momento:

- 🟢 **`fundamentos_nodejs/`**: Conceitos básicos, arquitetura do Node.js, execução de scripts e fundamentos gerais do ambiente.
- 🟢 **`modulos/`**: Trabalhando com o sistema de módulos do Node (CommonJS/ES Modules), criação, importação e exportação (Core modules).
- 🟢 **`lendo_inputs/`**: Como capturar e processar dados inseridos pelo usuário direto no terminal (usando o módulo nativo `readline`).
- 🟢 **`abstracao_input/`**: Melhorando a captura de inputs dos usuários através de bibliotecas de terceiros (como o pacote `inquirer`).
- 🟢 **`event_loops/`**: Entendendo a fundo a arquitetura assíncrona do Node.js, o funcionamento do Event Loop, Call Stack e execução não-bloqueante.
- 🟢 **`chalk/`**: Trabalhando com pacotes externos do npm (ex: Chalk) para estilização de outputs e textos coloridos no console.

## 🏃 Como rodar os códigos

1. Certifique-se de ter o **Node.js** instalado na sua máquina.
2. Clone este repositório para o seu ambiente local:
   ```bash
   git clone https://github.com/imanthonypeter/Udemy_Node_Express.git
   ```
3. Instale as dependências gerais do projeto:
   ```bash
   npm install
   ```
4. Navegue até a pasta do módulo que deseja testar e execute o arquivo principal usando o Node. Exemplo:
   ```bash
   cd fundamentos_nodejs
   node index.js
   ```
